# Für den Vorstand: was die Website von euch braucht

Dinge, die nur der Vorstand erledigen oder entscheiden kann. Wenn etwas erledigt ist: Datum dazu und abhaken. Neue Punkte unten anhängen, mit Datum und woher sie kommen.

Stand: 26.11.2026

## Spenden (Seite `/spenden`, Story S5.14)

- [ ] **PayPal einrichten** (26.11.2026)
  1. Geschäftskonto auf den Verein anlegen (paypal.com/de → Geschäftskonto), mit dem Spendenkonto als Bankverbindung.
  2. Beim PayPal-Support den ermäßigten Tarif für gemeinnützige Organisationen beantragen (Freistellungsbescheid nötig). Laut Ratgeberseiten rund 1,5 % + 0,35 € statt 2,49 % + 0,35 €; bitte bei PayPal bestätigen lassen.
  3. „Spenden-Button erstellen“ → den Link mit `hosted_button_id=…` kopieren.
  4. Im CMS: Seite „Spenden“ → Block „Spenden“ → Feld „PayPal-Link“ eintragen. Karte und QR-Code erscheinen dann von selbst.
- [ ] **betterplace.org einrichten** (26.11.2026)
  1. Organisation registrieren (betterplace.org → „Spenden sammeln“). Gebraucht werden Freistellungsbescheid, Satzung und Vereinsregisterauszug. Kostenlos, betterplace behält 2,8 % je Spende.
  2. Ein Projekt anlegen, z. B. „Maschinen & Material für die offene Werkstatt“, mit Fotos und Zielbetrag.
  3. Im CMS: Block „Spenden“ → Feld „betterplace-Link“ eintragen.
- [ ] **Wunschliste für Sachspenden** (26.11.2026): Die Liste auf `/spenden` („Das suchen wir“ und „Bitte nicht“) sind Beispiele. Bitte durch echte Wünsche ersetzen (im CMS, Seite „Spenden“).
- [ ] **Ansprechpartner bestätigen** (26.11.2026): Für Spendenquittungen und Sachspenden steht office@makerspacebonn.de auf der Seite. Stimmt das, oder soll es eine andere Adresse sein?
